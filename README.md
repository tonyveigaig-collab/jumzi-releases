# JUMZI para computador

App oficial do [JUMZI](https://jumzi.vercel.app) para Windows, macOS e Linux.

**Baixe pela central oficial: https://jumzi.vercel.app/download**

Este repositório guarda o código do app de computador (Electron) e a esteira que gera, testa e publica
os instaladores a cada versão. O escritório em si (site e servidor) é carregado de jumzi.vercel.app.

| Sistema | Arquivos |
| --- | --- |
| Windows 10/11 (x64, ARM64) | `JUMZI-Setup-*.exe`, `JUMZI-*.msi` |
| macOS 11+ (chip Apple, Intel) | `JUMZI-arm64.dmg`, `JUMZI-x64.dmg` |
| Linux (x64, ARM64) | `.deb`, `.rpm`, `.AppImage` |
